# live-minutes-translator

日本語・English・中文の三言語で、議事録をリアルタイムに共有・翻訳する単一HTMLページです。
どの言語のページに書いても、その行が原文になり、残り2言語に行単位で翻訳されます。

`index.html` は claude.ai のアーティファクト「三言語議事録」(runtime contract 0.2.90) のスナップショットです。

## 仕組み

- 行ごとに確定します。カーソルが別の行へ移ったとき、または入力が止まって設定秒数（3/5/10秒、または確定しない）がたったときです。
- 確定した行は、原文の言語・本文・バージョン番号とあわせて共有DB（`meetings/main/blocks`）に保存されます。
- 保存に成功すると `sample.json()` で Claude に翻訳を依頼します。直前の最大4行を文脈として渡し、返答は `{"en": "...", "zh": "..."}` 形式のJSONです。
- 書き戻す前にバージョン番号を照合し、翻訳中に原文が再編集されていれば古い訳は捨てます。
- 行頭の記号（`#`、`-`、`1.`、`>`）は翻訳せず全言語で共通です。記号だけの変更では再翻訳しません。
- 他の閲覧者の画面には、DBの変更通知（`onSnapshot`）で反映されます。

## 動作環境の制約

このページは claude.ai のアーティファクト上で動く前提です。次の機能は `window.claude.use()` が提供するもので、ブラウザ単体では動きません。

| 用途 | capability |
| --- | --- |
| 共有データの保存と同期 | `db` |
| 翻訳（Claude呼び出し） | `sample` |
| Markdown保存 | `downloads` |

公開アーティファクトのCSPは外部ホストへの `fetch` / `WebSocket` を禁止します。そのため、このページからローカルLLMのサーバーへ直接接続することはできません。

## 今後の仕様（予定）

- deskmini 上で動く独立アプリにする。
- 翻訳は Claude ではなく、**ローカルLLM**で行う。
- 使用するツール・モデル・言語は、deskmini 側で決める（未定）。

独立アプリにするため、現行ページが claude.ai の capability に頼っている次の3点を、自前の仕組みに置き換える必要があります。

| 現行 | 置き換え先 |
| --- | --- |
| `db`（共有保存と同期） | アプリ自身の保存先と、複数画面への同期 |
| `sample`（Claude による翻訳） | ローカルLLMによる翻訳 |
| `downloads`（Markdown保存） | ブラウザ標準のダウンロード |

翻訳の入出力（行単位、直前の数行を文脈にする、原文のバージョンを照合して古い訳を捨てる、`ja`/`en`/`zh` を返す）は、現行のまま引き継ぎます。

## 書き方

| 入力 | 意味 |
| --- | --- |
| `# ` `## ` `### ` | 見出し |
| `- ` | 箇条書き（`Enter` で続行、空項目で `Enter` で解除、`Tab` / `Shift+Tab` で字下げ） |
| `1. ` | 番号付きリスト（番号は自動で増える） |
| `> ` | 引用 |
